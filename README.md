# ❤️ Father's Day Tribute Website

A heartfelt Father's Day tribute website built with **HTML, CSS, and JavaScript** — designed to celebrate the love, sacrifices, and unforgettable memories shared with a father.

This project is more than a simple webpage; it's a digital memory album filled with appreciation, gratitude, and personal moments dedicated to one of the most important people in life.

🌐 **Live Website:** https://codexpertdev.github.io/fathers-day-website/

---

# 👨‍👧 About The Project

This website was created as a special Father's Day gift to honor a father’s unconditional love, guidance, and support.

Through elegant design, meaningful storytelling, and cherished memories, this tribute captures the impact a father has on shaping a child's life.
